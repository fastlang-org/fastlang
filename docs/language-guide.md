# FastLang Language Guide

This page is the short overview of FastLang. For the maintainable reference, use the modular [documentation index](index.md).

FastLang is a statically typed native language with explicit values, references, pointers, generic functions, pattern matching, compile-time facilities, macros, foreign-function support, and standard-library modules for I/O, networking, documents, web applications, time, threads, and SQLite.

The reference is intentionally split by feature:

- [Syntax](language/syntax.md)
- [Types](language/types.md)
- [Functions](language/functions.md)
- [Control flow](language/control-flow.md)
- [Objects](language/objects.md)
- [Macros](language/macros.md)
- [Compile-time programming](language/compile-time.md)
- [Projects and `Fast.toml`](projects.md)
- [Compiler CLI](compiler.md)
