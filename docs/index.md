## Documentation policy

These pages describe the intended public language surface. Internal planning notes, discarded syntax, implementation experiments, and test-only fixtures do not define the language contract.

The internal design notes remain in [internal/todo.fast](internal/todo.fast) for planning, but they are not part of the public API documentation.
